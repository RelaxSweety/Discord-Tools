# Discord Message Cleaner

Version: 0.1.0 (prototype)

## Project structure

- `src/` — Tampermonkey userscript source
- `docs/` — installation, usage, and test guidance
- `tests/` — manual verification checklist

## Planned features

Selected channel/DM queue, author verification, historical scrolling, pause/resume/stop, deletion progress, and CSV export.

The userscript has not yet been published to `src/`; do not assume the prototype has been tested against Discord's current UI.
